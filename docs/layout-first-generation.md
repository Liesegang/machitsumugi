# 街区から設計する生成方式（試作）

`experiment/layout-first-generation` では、完成時の空間構成から地図全体を設計する方式を検証します。
生成の入力は街の設定と地形です。道路・街区・敷地・建物を全域で新しく構成します。
従来方式の地図は街並みを評価するための比較資料として保存し、生成する道路や建物の初期値には使いません。
設定の「生成方式」で選択します。保存済みプロジェクトの方式と地図は保持し、明示的な生成操作で新しい地図を作ります。
この実験ブランチの新規プロジェクトは「街区から設計（試作）」を初期値にします。方式が未記録の旧プロジェクトは従来方式として読み込みます。

## 設計順序

1. 計算済みの標高・水域・斜面を読み、中心部、近隣住区、就業地、農村縁辺の空間構成を決める。
2. 学校、病院、大学、公園などの敷地と入口を予約する。
3. 連続する鉄道本線、駅舎と駅前広場を測量する。
4. 外部道路、主要中心間の幹線、集散道路を接続し、実際の道路で囲まれた街区を作る。
5. 旧中心部の細かな街区、戦後の整備街区、郊外の住区などの構成に応じて生活道路を分ける。
6. 実際の街路と駅への経路を使って用途・規模を決め、住宅、店舗、集合住宅の接道敷地を配置する。
7. 採用した都市用地と周辺の農地・森林・草地をまとまりとして区分する。
8. 町域と、開発・道路改良・物理的な建て替えの履歴を記録する。

人口や資金の年次ループで街の形を決める方式とは分けています。
地形の侵食・堆積と河川計算は共通のものを使い、この比較のために再実装していません。
建築用地と道路では水域、地盤、勾配、鉄道、既存の予約地を引き続き検査します。
施設の入口が開設時点の公道をたどって区域外へ到達できるかを、生成後に独立したグラフで検査します。
選択した施設が欠ける場合や外部接続が成立しない場合を、完成扱いにはしません。

## 年代の扱い

旧市街、鉄道開通、戦後の整備、郊外開発の段階を空間に割り当てます。
道路の成立年と拡幅年、土地の取得年と建物の建築年を区別します。
建て替えでは新しい物理的な建物IDと形状を記録し、同じ敷地の過去の建物も保存します。
人口減少は現代の入居・空き家状態へ反映します。
表示年代の変更は保存した履歴の切り出しだけを行います。

これは史実から校正した都市成長予測ではありません。
開発段階の年代は生成上の仮定であり、道路や建物の履歴に未記録の出来事を説明文で補いません。

## 比較と検証

旧方式は「歴史から生成」で保持しています。
方式を切り替えただけで保存地図を再生成しません。
同じシードと条件で明示的に生成して、地形・街路・建物・施設・年代別表示を比較できます。

比較では、均一な直交街区と大きな集合住宅が並ぶ試作に、街全体の構成としての退行を確認しました。
従来方式の右下だけを補完した検証は、全域の新しい生成方式を評価する結果には含めません。
施設の配置成功、接続・衝突検査の通過、空白面積の減少だけで、見た目の品質を合格にしません。

完成図では、全域の道路階層、中心と商業地の関係、地区ごとの街区の違い、住宅と集合住宅の規模、都市用地と農地のまとまりを確認します。
新方式が作った道路・敷地・建物の出所も記録し、旧図を部分的に継ぎ足した出力と混同しません。
現在の全域試作では外部道路の連続と中心部の中層化を確認していますが、郊外の格子の単調さと角張った市街地境界は未解決です。リアリティの評価は未合格とします。
比較ページにはシード、広さ、駅数、地形、地域の規模、交通設定と、実際に使った生成方式を明記します。
縮小した検証例にはその条件を明記し、利用者の設定による全域生成と区別します。

構成を既知の地盤で検査する統合テストと、実際の侵食・堆積から作った地形での描画・接続検査を分けます。
高速な検査は `npm run test:quick`、ビルドは `npm run build`、静的検査は `npm run lint` で実行します。
地形を再計算せず都市設計だけを計測した値を、地形を含む全生成時間として扱いません。
